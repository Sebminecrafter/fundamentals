Fundamentals allows you to configure almost every message from commands or checks by modifying
its key in `lang.yml`. Most entries have built-in placeholders like %player%, and
(if it is installed) can use PlaceholderAPI.

Player-specific placeholders are not yet available with PlaceholderAPI.
