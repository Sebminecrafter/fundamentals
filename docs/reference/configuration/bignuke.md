# BigNuke

`bignuke.distance` controls the radius of the circular TNT pattern used by `/bignuke`.

```yaml
bignuke:
  distance: 20
```

The value is a distance in blocks (radius) and is hard capped at `50`.
Enable or disable `/bignuke` with `enabled.cmds.bignuke`.

See [Commands](../commands/) and [Permissions](../permissions/) for command usage and permissions.
