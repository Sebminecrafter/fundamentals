# Configuration

Fundamentals reads its settings from `plugins/Fundamentals/config.yml`.

After changing `config.yml`, restart the server or use the plugin's reload command if available.
The file is created automatically the first time the plugin starts.

Start with the [configuration reference](../../reference/configuration/) for an overview of the
available sections. Individual settings are documented in:

- [Enabled modules and commands](../../reference/configuration/enabled/)
- [Chat](../../reference/configuration/chat/)
- [TPA, homes, and warps](../../reference/configuration/teleports/)
- [Random teleport](../../reference/configuration/rtp/)
- [Sounds](../../reference/configuration/sounds/)
- [BigNuke](../../reference/configuration/bignuke/)
- [Server MOTD](../../reference/configuration/motd/)
- [Miscellaneous settings](../../reference/configuration/misc/)

For custom plugin messages, edit [`lang.yml`](../../reference/language/).
