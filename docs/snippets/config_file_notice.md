!!! note
    Fundamentals' config files use a `version:` value for tracking when to add new values to
    a config file. Editing this value may lead to unexpected or broken changes.
    ??? warning "What if an update breaks my config?"
        If you are worried about your config breaking on an update,
        you can change the version to something really high.
        Do note, though, that this is unsupported behavior
        and may lead to broken configs.
